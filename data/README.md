# Data Directory

This directory contains all data files for the thiLLMo project.

## Directory Structure

### `/proverbs/`
Kikuyu proverb datasets:
- Raw proverb collections
- Annotated proverbs with cultural context
- Translation pairs (Kikuyu-English)
- Cultural metadata and explanations

### `/results/`
Experimental results and outputs:
- Model evaluation results
- Performance metrics
- Generated translations
- Comparison analyses

## Data Handling Guidelines

- **Privacy**: Ensure cultural data is handled respectfully
- **Attribution**: Proper attribution for cultural knowledge sources
- **Format**: Use consistent data formats (JSON, CSV, etc.)
- **Documentation**: Document data sources and preprocessing steps
- **Backup**: Regular backups of important datasets

## File Naming Conventions

- Use descriptive names
- Include version numbers where applicable
- Follow consistent naming patterns
- Include date stamps for time-sensitive data
