# Raw Data Directory

This directory contains raw, unprocessed data extracted from expert proverb collections before transformation into evaluation-ready gold standard formats.

## Overview

Raw data files are generated by the **Expert Proverb Extraction Framework** (see `scripts/extract_expert_proverbs.py`). Each expert source is configured in `scripts/config/expert_sources.yaml` with metadata, extraction rules, and quality thresholds.

**Current Framework Version**: 2.0 (Generic multi-source support)

## Contents

### Primary Dataset: `ireri_expert_proverbs.csv`

Margaret Wambere Ireri's curated collection of 100 Kikuyu proverbs about money and wealth, extracted from her 2014 academic publication.

**Source**: "A Collection of 100 Proverbs and Wise Sayings of the Gikuyu (Kenya) About Money and Wealth" by Margaret Wambere Ireri (August 2014)

**Standard Columns** (all expert sources):
- `proverb_number`: Sequential number from original collection
- `kikuyu_proverb`: Native language proverb text (Kikuyu for Ireri)
- `english_translation`: Expert-provided English translation
- `kiswahili_translation`: Kiswahili translation (if available)
- `cultural_interpretation`: Cultural meaning and context
- `wealth_prosperity_context`: Domain-specific relevance
- `teaching_message`: Moral or practical teaching
- `biblical_parallel`: Related biblical verses (if applicable)
- `references`: Academic source citations
- `category`: Domain category (W=Wealth, M=Money, WM=Both)
- `page_number`: PDF page number for source verification

**Extraction Method**: Configuration-driven PDF extraction with pattern matching (see `scripts/config/expert_sources.yaml` for Ireri's extraction rules)

**Ireri Collection Quality**:
- 197 total entries extracted (includes proverb variations and detailed entries)
- 100% Kikuyu text coverage
- 97% English translation coverage
- 50% cultural interpretation coverage
- Cultural authenticity: 5.0/5.0 (expert validated)

## Data Pipeline (v2.0)

```
PDF Source → extract_expert_proverbs.py --source ireri → ireri_expert_proverbs.csv
                                                                    ↓
                                                 convert_to_gold_standard.py --source ireri
                                                                    ↓
                                            data/evaluation/gold_standard_ireri.csv
```

**Configuration-Driven**: All extraction parameters (page ranges, patterns, thresholds) defined in `scripts/config/expert_sources.yaml`.

## Usage

### Extract Data from Expert PDF (Generic Framework)

```bash
# Extract from configured source (recommended)
python3 scripts/extract_expert_proverbs.py --source ireri

# Or specify custom PDF path
python3 scripts/extract_expert_proverbs.py --source ireri \
    --pdf data/sources/OPIT_RAI9001_Proverbs_Wealth_Prosperity_v1.pdf \
    --output data/raw/ireri_expert_proverbs.csv
```

### Run Complete Pipeline (Extract + Convert + Report)

```bash
# Full pipeline for any configured source
python3 scripts/gold_standard_pipeline.py --source ireri

# Or specify custom paths
python3 scripts/gold_standard_pipeline.py --source ireri \
    --pdf data/sources/OPIT_RAI9001_Proverbs_Wealth_Prosperity_v1.pdf
```

**Result**: Extracts raw proverbs, validates quality, converts to gold standard, generates quality report.

### Load Raw Data in Python

```python
import pandas as pd
from config import get_output_path

# Load raw extraction (v2.0 naming)
raw_path = get_output_path('ireri', 'raw_csv')  # Auto from config
raw_proverbs = pd.read_csv(raw_path)

# Or use direct path
raw_proverbs = pd.read_csv('data/raw/ireri_expert_proverbs.csv')

# Explore the data
print(f"Total proverbs: {len(raw_proverbs)}")
print(f"Unique proverb numbers: {raw_proverbs['proverb_number'].nunique()}")

```

## Adding New Expert Sources

To extract proverbs from a new expert collection:

1. **Add configuration** in `scripts/config/expert_sources.yaml`:
```yaml
sources:
  new_expert:
    author: "Dr. Expert Name"
    year: 2025
    language: "swahili"
    language_code: "sw"
    domain: "family_wisdom"
    extraction:
      pattern_type: "numbered"
      start_page: 1
      end_page: 100
    # ... more config ...
```

2. **Run extraction**:
```bash
python3 scripts/extract_expert_proverbs.py --source new_expert \
    --pdf path/to/expert_collection.pdf
```

3. **Automatic output**: `data/raw/new_expert_expert_proverbs.csv`

**No code changes required!** Framework handles all extraction, validation, and output generation.
