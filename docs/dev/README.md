## 🚀 **Quick Start for Developers**

1. **Clone and Setup**
   ```bash
   git clone <repository-url>
   cd opit-rai9001-thiLLMo
   git checkout dev
   ```

2. **Review Branching Strategy**
   - Read [BRANCHING_STRATEGY.md](./BRANCHING_STRATEGY.md)
   - Understand the dev → main workflow

3. **Start Development**
   - Create feature branches from `dev`
   - Use `cz commit` for consistent commit messages
   - Include AI prompt logging in commits
