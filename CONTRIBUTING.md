# Contributing to thiLLMo

Thank you for your interest in the thiLLMo project! This document provides guidelines for contributing to our culturally faithful Kikuyu proverb translation system.

## Project Overview

thiLLMo is an academic research project focused on preserving and translating Kikuyu cultural wisdom through advanced AI techniques. The project uses Ontology-Grounded Retrieval Augmented Generation (OG-RAG) to ensure culturally faithful translations.

## Current Status

**This is an active academic research project** (RAI9001) at the Open Institute of Technology (OPIT), supervised by Marzieh Bakhshandeh.

## Types of Contributions

### Academic Collaboration
- Research methodology improvements
- Cultural linguistics expertise

- Evaluation framework development

### Cultural Consultation
- Kikuyu linguistic expertise
- Cultural context validation
- Traditional knowledge verification
- Community engagement guidance

### Technical Contributions
- Code improvements and bug fixes
- Documentation enhancements
- Performance optimizations
- Testing framework expansion

## How to Contribute

### For Academic Researchers
1. Contact the student researcher: Watson Ndethi <charleswatsonndeth.k@students.opit.com>
2. Provide your research background and area of expertise
3. Discuss potential collaboration opportunities
4. Follow OPIT academic collaboration protocols

### For Cultural Consultants
1. We deeply value traditional knowledge and cultural expertise
2. All cultural contributions are acknowledged with full respect
3. Community consent and appropriate protocols are always followed
4. Contact us to discuss culturally appropriate collaboration methods

### For Technical Contributors
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes with proper documentation
4. Add tests if applicable
5. Commit your changes (`git commit -m 'Add amazing feature'`)
6. Push to the branch (`git push origin feature/amazing-feature`)
7. Open a Pull Request

## Development Guidelines

### Code Standards
- Follow PEP 8 for Python code
- Include comprehensive docstrings
- Add type hints for all functions
- Write unit tests for new features
- Maintain cultural sensitivity in all code comments

### Documentation Standards
- Update README.md for significant changes
- Document cultural concepts respectfully
- Include usage examples
- Maintain academic citation standards

### Cultural Sensitivity Guidelines
- All cultural content must be handled with utmost respect
- Traditional knowledge requires appropriate attribution
- Community consent is essential for cultural data
- Avoid cultural appropriation or misrepresentation

## Research Ethics

This project adheres to strict ethical guidelines:
- Cultural knowledge is treated with deep respect
- Community consent is obtained for all cultural content
- Traditional knowledge contributors are properly acknowledged
- Academic integrity standards are maintained throughout
