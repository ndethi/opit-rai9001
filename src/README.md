# Source Code Organization

This directory contains the main source code for the thiLLMo project.

## Directory Structure

### `/ontology/`
Contains ontology-related code and files:
- Ontology definitions and schemas
- Ontology validation and processing
- Cultural knowledge representation

### `/og-rag-system/`
Core OG-RAG (Ontology-Grounded RAG) system implementation:
- RAG pipeline components
- Retrieval mechanisms
- Generation modules
- Integration with ontology

### `/evaluation/`
Evaluation frameworks and metrics:
- Evaluation scripts
- Metrics calculation
- Benchmark comparisons
- Result analysis tools

## Development Guidelines

- Follow Python best practices
- Include proper documentation
- Write comprehensive tests
- Use type hints where appropriate
- Follow the established code style
