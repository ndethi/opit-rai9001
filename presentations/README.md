# Presentations

This directory contains all presentation materials for the thiLLMo project.

## Directory Structure

### `/defense-preparation/`
Materials for thesis defense preparation:
- Draft presentation slides
- Defense practice materials
- Question and answer preparation
- Visual aids and demonstrations

### `/weekly-updates/`
Regular progress update presentations:
- Weekly supervisor meeting slides
- Progress report presentations
- Milestone review materials
- Status update documents

## Presentation Guidelines

- Use consistent branding and formatting
- Include clear, readable slides
- Prepare for various audience levels
- Include demo materials where appropriate
- Keep backups of all presentation files

## File Organization

- Date-stamp all presentation files
- Use descriptive filenames
- Include version numbers for major revisions
- Store both source files and exported PDFs
